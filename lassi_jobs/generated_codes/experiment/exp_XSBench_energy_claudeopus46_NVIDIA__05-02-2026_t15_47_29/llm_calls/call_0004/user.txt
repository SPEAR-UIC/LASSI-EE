# Summary of Key CUDA Energy Efficiency Techniques for NVIDIA A100

## 1. Memory Access Coalescing
Ensure that consecutive threads in a warp access consecutive memory addresses so the hardware can combine requests into minimal DRAM transactions. This means preferring Struct-of-Arrays (SoA) over Array-of-Structs (AoS) layouts and indexing such that thread `i` accesses `base + i`. Perfect coalescing can reduce DRAM transactions by up to 32× compared to fully strided access, directly cutting HBM2e power draw. **Most impactful for memory-bound kernels** where DRAM bandwidth utilization is near the roofline peak—such as random-access lookup workloads—because DRAM access energy dominates total consumption.

## 2. Shared Memory Use
Load tiles of global memory cooperatively into on-chip shared memory (up to 164 KB per SM on A100) and have threads read from there instead of repeatedly hitting HBM2e. Shared memory consumes roughly 100× less energy per access than DRAM. Avoid bank conflicts by ensuring thread access strides are not multiples of 32. **Most impactful when threads in the same block exhibit spatial reuse**—i.e., they read overlapping or nearby regions of global memory multiple times, as in stencil computations, matrix tiling, or shared energy-grid lookups.

## 3. Occupancy Optimization
Occupancy (active warps / maximum warps per SM) determines how effectively SMs are utilized; idle SMs still draw static power. On the A100, maximum occupancy is 64 warps (2048 threads) per SM. Occupancy is limited by per-thread register usage, per-block shared memory allocation, and block size. Use 128–256 threads per block as a default, apply `__launch_bounds__` to control register allocation, and query optimal configurations with `cudaOccupancyMaxPotentialBlockSize`. **Most impactful when register pressure or shared memory usage inadvertently limits active warps well below peak**, causing SMs to idle while waiting on memory latency with insufficient warps to hide it.

## 4. Warp Divergence Reduction
When threads within a warp take different branches, both paths execute serially with inactive threads masked, wasting execution unit energy and increasing active cycles. Mitigate by using branchless arithmetic (ternary operators, predicated instructions), keeping branch bodies short (≤4 instructions) so the compiler can predicate them, and sorting input data to group similar execution paths into the same warps. **Most impactful when kernels have data-dependent branching that varies across threads within a warp**, such as type-based dispatch or conditional interpolation in heterogeneous workloads.

## 5. Kernel Fusion
Merging consecutive kernels that operate on the same data eliminates intermediate DRAM round-trips and per-launch overhead (~5–15 µs each). Intermediate results remain in registers or shared memory instead of being written to and re-read from HBM2e. **Most impactful when a pipeline of short kernels passes moderate-to-large intermediate buffers through global memory**, making the inter-kernel data movement a significant fraction of total energy.

## 6. Read-Only Cache (`__ldg` and `const __restrict__`)
For arrays that are never written inside a kernel, use `__ldg()` intrinsics or declare pointers as `const __restrict__` to route loads through the A100's dedicated texture/L1 read-only cache path (256 KB L1). This reduces L2 contention and DRAM traffic for repeated reads to the same cache lines. **Most impactful for read-only lookup tables with any spatial or temporal locality**, including large cross-section arrays in Monte Carlo simulations where even modest cache hit rates offset expensive HBM2e accesses.

## 7. Arithmetic Precision Tradeoffs
On A100, FP32 throughput is approximately 8× higher than FP64 (77.6 vs. 9.7 TFLOPS), and FP32 values require half the memory bandwidth and register space. Switching from double to float—where application accuracy permits—reduces both compute energy and data movement energy. Use fast-math intrinsics (`__expf`, `__logf`, `__fdividef`) when ~22-bit precision suffices, and rely on fused multiply-add (FMA) for combined accuracy and throughput gains. **Most impactful for compute-bound kernels with heavy FP64 usage**, or memory-bound kernels where halving data width meaningfully reduces DRAM traffic.

## 8. Synchronization Minimization
`__syncthreads()` stalls all threads in a block until every thread arrives, serializing execution and preventing the scheduler from issuing useful work. Reduce barriers by moving them outside loops when shared data is unchanged across iterations, restructuring access patterns to eliminate mid-loop dependencies, and using warp-level primitives (`__syncwarp()`, `__ballot_sync()`, `__reduce_sync()`) when only intra-warp consistency is needed. For reductions, use shared-memory tree reduction to replace per-thread atomics with a single per-block atomic. **Most impactful in kernels with tight inner loops containing barriers or high-contention atomic operations**, where synchronization overhead becomes a significant fraction of execution time.

## 9. Prefetching and Transfer Optimization
Minimize host-device PCIe transfers (~32 GB/s) by keeping data GPU-resident across kernel invocations, using pinned memory (`cudaMallocHost`) when transfers are unavoidable, and overlapping transfers with computation via CUDA streams and `cudaMemcpyAsync`. Prefer explicit `cudaMalloc`/`cudaMemcpy` over unified memory to avoid implicit page migration costs. Within kernels, use `#pragma unroll` on short fixed-count loops to expose instruction-level parallelism and allow the compiler to schedule loads early, effectively prefetching data into registers. **Most impactful when kernels are launched repeatedly on data that can remain on the GPU**, or when loop unrolling enables the memory system to service multiple outstanding loads concurrently, hiding latency in memory-bound workloads.

# Structured Technical Description: XSBench CUDA — Energy Efficiency Analysis

---

## 1. Overall Algorithm and GPU Resource Utilization Profile

XSBench is a Monte Carlo neutron transport proxy application that performs continuous-energy macroscopic cross-section lookups. Each lookup involves: (a) sampling a random energy and material via an LCG pseudo-random number generator, (b) performing a binary search over a unionized energy grid, nuclide grid, or hash grid to locate bounding energy indices, and (c) interpolating microscopic cross-section data across all nuclides in the selected material, accumulating five reaction-channel macro cross sections.

**Compute vs. Memory Bound:** The application is predominantly **memory-bound**. The core work consists of binary searches over large data structures (`unionized_energy_array`, `index_grid`, `nuclide_grid`) followed by interpolation reads from `NuclideGridPoint` structures. Arithmetic intensity is low: each loaded grid point yields only a handful of multiply-add operations (interpolation across 5 XS channels). The `NuclideGridPoint` structure is 48 bytes (6 doubles), so each interpolation step loads 96 bytes (two grid points) to perform roughly 15 FLOPs.

**Access Pattern:** Memory access is fundamentally **random/scattered**. Each thread samples a random energy, leading to a random index into the energy and nuclide grids. Adjacent threads within a warp will, in general, access completely unrelated locations in the nuclide grid. The binary search itself also produces random, data-dependent access patterns. The optimized variants (4, 5, 6) that sort by material and/or energy improve spatial locality and cache reuse, shifting the profile slightly less memory-bound by improving L2 hit rates.

## 2. Kernel Launch Configurations and Occupancy Analysis (A100)

### Baseline (kernel_id = 0): `xs_lookup_kernel_baseline`
- **Block size:** 256 threads (1D)
- **Grid size:** `ceil(lookups / 256)` blocks (1D)
- **Occupancy estimate:** 256 threads/block = 8 warps/block. A100 SMs support up to 64 warps (2048 threads). With 256 threads/block, up to 8 blocks can be resident per SM (limited by register and shared memory pressure). Register usage for this kernel is likely high due to double-precision variables and the deep call tree (`calculate_macro_xs` → `calculate_micro_xs` → `grid_search`/`grid_search_nuclide`). Estimated occupancy: **moderate (50–75%)**, depending on register spill. The 256-thread block size is reasonable for the A100.

### Optimization 1: `sampling_kernel` and `xs_lookup_kernel_optimization_1`
- **Block size:** 32 threads (1 warp per block)
- **Grid size:** `ceil(lookups / 32)` blocks
- **Occupancy estimate:** Only 32 threads per block = 1 warp/block. A100 can schedule up to 32 blocks per SM (hardware limit), yielding at most 32 warps = 1024 threads per SM out of 2048 maximum. **Theoretical occupancy ceiling: 50%.** Actual occupancy will be lower if register pressure limits resident blocks below 32. This is a **suboptimal block size** for energy efficiency; larger blocks (128–256) would improve occupancy.

### Optimization 2: `xs_lookup_kernel_optimization_2`
- **Block size:** 32 threads
- **Grid size:** `ceil(lookups / 32)` blocks
- **Same occupancy concern as Optimization 1.** Additionally, each of the 12 material kernels launches over ALL lookups, with most threads immediately returning (material mismatch). This wastes launch overhead and causes most warps to execute only the bounds check and early exit, burning scheduling resources for minimal useful work.

### Optimization 3: `xs_lookup_kernel_optimization_3`
- **Block size:** 32 threads
- **Grid size:** `ceil(lookups / 32)` blocks
- **Occupancy:** Same 50% ceiling as above. Two kernel launches (fuel, non-fuel), each scanning all lookups. Approximately 86% of threads in each launch early-exit.

### Optimization 4: `xs_lookup_kernel_optimization_4`
- **Block size:** 32 threads
- **Grid size:** `ceil(n_lookups_per_material[m] / 32)` per material
- **Occupancy:** 50% ceiling. However, after sorting, each kernel launch is sized to exactly the number of lookups for that material, so all threads do useful work. Small materials (e.g., material 8 with 0.8% of lookups) will launch very few blocks, potentially under-utilizing the GPU.

### Optimization 5: `xs_lookup_kernel_optimization_5`
- **Block size:** 32 threads
- **Grid size:** Sized per partition (fuel vs. non-fuel)
- **Occupancy:** Same 50% ceiling.

### Optimization 6 (host function, reuses `xs_lookup_kernel_optimization_4`)
- **Block size:** 32 threads
- **Grid size:** Per-material sized
- **Occupancy:** Same 50% ceiling.

**Summary:** All optimized variants use 32-thread blocks, which caps theoretical occupancy at 50% on A100. The baseline uses 256 threads, which is more appropriate. Increasing block size to 128 or 256 in the optimized variants would be a straightforward energy-efficiency improvement.

## 3. Global Memory Access Patterns — Coalescence Analysis

### `sampling_kernel`
- **Writes to `GSD.p_energy_samples[i]` and `GSD.mat_samples[i]`:** Consecutive threads write to consecutive indices. These writes are **fully coalesced** (consecutive thread → consecutive 8-byte or 4-byte address).
- **Reads:** No global memory reads (seed is computed, not loaded).

### `xs_lookup_kernel_baseline` and all XS lookup kernel variants
The following access patterns apply to the core lookup logic shared across all kernel variants:

- **`GSD.num_nucs[mat]`:** `mat` varies randomly across threads in a warp (baseline) or is uniform within a warp (optimized sorted variants). In the baseline, this is a **scattered** 4-byte read. In sorted variants, all threads in a warp read the same `mat`, so this becomes a **broadcast** (L1 cache efficient).

- **`GSD.mats[mat * max_num_nucs + j]` and `GSD.concs[mat * max_num_nucs + j]`:** Accessed in a loop over nuclides in the material. In the baseline, different threads have different `mat`, so these reads are **scattered** across widely separated rows of the material/concentration arrays. In sorted variants, all threads share the same `mat`, so all threads read the same `j`-indexed element — this is a **broadcast** pattern, very cache friendly.

- **`GSD.unionized_energy_array` (binary search via `grid_search`):** Each thread performs an independent binary search with a random target energy. Access is **highly scattered** — each thread probes different indices at each iteration of the binary search. Within a warp, 32 threads will access 32 unrelated locations per binary search step. This is the single worst coalescence pattern in the code. In Optimization 6 (energy-sorted), nearby threads search for nearby energies, which dramatically improves spatial locality and L2 cache reuse, but individual warp-level transactions are still not perfectly coalesced.

- **`GSD.index_grid[idx * n_isotopes + nuc]`:** After the binary search, each thread reads index data at a position determined by its unique `idx` and the nuclide ID. In the baseline, `idx` varies randomly across threads, producing **scattered** reads across a potentially enormous array (`n_isotopes * n_gridpoints * sizeof(int)` can be multiple GB for unionized grid). In energy-sorted variants, nearby threads have similar `idx`, improving cache line reuse.

- **`GSD.nuclide_grid[nuc * n_gridpoints + index]`:** This is the most critical access. Each thread reads two consecutive `NuclideGridPoint` structures (low and high) for interpolation. The structures are 48 bytes each (fitting in one or two 128-byte cache lines). Access is **scattered** because each thread has a different `index` within the nuclide's grid. Two 48-byte AOS reads per nuclide per thread. In the energy-sorted case, nearby threads access nearby grid points within the same nuclide, significantly improving L2 hit rates.

- **`GSD.p_energy_samples[i]` and `GSD.mat_samples[i]` (optimized kernels):** Consecutive threads read consecutive indices. **Fully coalesced.**

- **`GSD.verification[i]`:** Single write per thread to consecutive addresses. **Fully coalesced.**

**Overall Assessment:** The baseline kernel has severely scattered global memory access. The progressive optimizations (especially 4 and 6) improve this substantially via sorting, but fundamental random-access patterns in the nuclide grid remain.

## 4. Shared Memory Usage

### Current Usage
**No kernel in the entire codebase uses shared memory.** There are zero `__shared__` variable declarations across all kernel implementations.

### Potential Uses

- **Material data caching:** The `num_nucs`, `mats`, and `concs` arrays for a given material are small (at most ~321 nuclides × 12 bytes = ~3.8 KB for the largest material). When all threads in a block look up the same material (as in the sorted variants), this data could be loaded cooperatively into shared memory once, eliminating redundant global memory reads across threads.

- **Binary search acceleration:** For the unionized energy grid binary search, a block-cooperative search strategy could be employed where threads within a block collectively narrow the search range, sharing intermediate bounds via shared memory.

- **NuclideGridPoint caching:** If threads within a warp/block access nearby nuclide grid points (as occurs after energy sorting), a small shared-memory cache or prefetch buffer could reduce redundant L2 accesses.

- **`pick_mat` distribution table:** The 12-element `dist[]` array is currently placed in local memory (likely register or L1). It could be declared `__shared__` or `__constant__` to avoid per-thread duplication (96 bytes × 32 threads per warp).

## 5. Warp Divergence Analysis

### `xs_lookup_kernel_baseline`
1. **`if( i >= in.lookups ) return;`** — Divergence only in the final block (at most 255 idle threads out of 256). Negligible.
2. **`pick_mat` function:** Contains a loop with data-dependent early return (`if( roll < running ) return i;`). Since each thread has a different random `roll`, threads within a warp will return at different iterations. **Moderate divergence** — up to 12 iterations with threads peeling off. INTENTIONAL behavior; the distribution fractions define the physics model.
3. **`calculate_macro_xs` — `for( int j = 0; j < num_nucs[mat]; j++ )`:** In the baseline, different threads have different materials with vastly different nuclide counts (4 to 321). The warp executes for `max(num_nucs[mat])` iterations across all active threads. If one thread has fuel (321 nuclides) and others have water (4 nuclides), 317 iterations run with most threads idle. **Severe divergence.** This is the primary motivation for the material-sorted optimized variants.
4. **`calculate_micro_xs` — grid type branches (`if grid_type == NUCLIDE`, `else if UNIONIZED`, `else HASH`):** All threads in a kernel launch use the same `grid_type`, so **no divergence** — the branch is uniform.
5. **`calculate_micro_xs` — boundary checks (`if( idx == n_gridpoints - 1 )`, `if( index_data[...] == n_gridpoints - 1 )`):** Data-dependent, but the edge case is rare (only one index value out of thousands triggers it). **Minimal divergence.**
6. **`grid_search` and `grid_search_nuclide` — `while( length > 1 )` with `if( A[examinationPoint] > quarry )`:** The while loop runs for `log2(n)` iterations in all threads (uniform trip count), but the branch direction (`upperLimit = ...` vs `lowerLimit = ...`) is data-dependent and will differ across threads. **Moderate divergence** at each binary search step — the warp must execute both paths. This is inherent to binary search on random data.
7. **Hash grid edge-case checks (`if( p_energy <= e_low )`, `else if( p_energy >= e_high )`):** Data-dependent. **Rare divergence** — most lookups fall in the normal case.
8. **Verification max-finding loop (`for j = 0..4; if macro_xs_vector[j] > max`):** The comparison is data-dependent, but the loop is short (5 iterations) and fully unrollable. **Negligible divergence.**

### `xs_lookup_kernel_optimization_2`
9. **`if( mat != m ) return;`** — In unsorted data, only ~1/12th of threads match the target material. **Catastrophic divergence**: nearly all threads in most warps immediately exit. Entire warps where no thread matches still consume scheduling resources.

### `xs_lookup_kernel_optimization_3`
10. **`if( ((is_fuel == 1) && (mat == 0)) || ((is_fuel == 0) && (mat != 0)) )`** — Similar to above but binary (fuel vs. non-fuel). Fuel is 14% of lookups, so in the fuel kernel, ~86% of threads early-exit. **Significant divergence.**

### `xs_lookup_kernel_optimization_4` and `_5`
11. **`if( mat != m ) return;`** (in opt 4) — After sorting, this should rarely trigger (only possible at material boundaries within the sorted array, affecting at most one warp per material). **Minimal divergence.**
12. **`if( i >= n_lookups ) return;`** — Only in the last block per material launch. **Negligible.**

## 6. Data Types — Double-Precision vs. Single-Precision

### Current double-precision operations:

1. **`NuclideGridPoint` structure:** All six fields (`energy`, `total_xs`, `elastic_xs`, `absorbtion_xs`, `fission_xs`, `nu_fission_xs`) are `double` (48 bytes per point). This is the dominant data structure; the entire nuclide grid is double-precision.

2. **`p_energy` (particle energy):** `double` throughout all kernels.

3. **`concs` array:** Material concentrations stored as `double`.

4. **`unionized_energy_array`:** Stored as `double`.

5. **`macro_xs_vector[5]` and `xs_vector[5]`:** Local arrays of `double`.

6. **Interpolation factor `f`:** Computed as `double`.

7. **`LCG_random_double`:** Returns `double`, operates on `uint64_t` seed. The division `(double)(*seed) / (double) m` produces a double-precision random value.

8. **`dist[12]` in `pick_mat`:** Material distribution probabilities stored as `double`.

9. **Hash grid energy computation `du = 1.0 / hash_bins`:** `double` division.

### Replacement feasibility:

**The use of double precision in this code is INTENTIONAL and physics-motivated.** Monte Carlo neutron transport codes require double precision for energy lookups because:
- Energy grid searches span many orders of magnitude, and single-precision (7 decimal digits) is insufficient to distinguish adjacent grid points in fine-resolution regions.
- Interpolation accuracy directly affects cross-section values, which compound across hundreds of nuclides in the macroscopic XS calculation.
- Verification checksums are sensitive to floating-point precision; switching to float would change the checksum and cause verification failure.

**However, from a pure energy-efficiency perspective**, the following could potentially use `float` without significantly affecting result quality in a non-verification context:
- The interpolation factor `f` computation and the five multiply-accumulate operations per nuclide in `calculate_micro_xs` (mixed-precision: load as double, compute interpolation in float).
- The `concs` multiplications in `calculate_macro_xs` (concentration-weighted accumulation).
- The `dist[]` array and comparisons in `pick_mat`.

**A100 specifics:** The A100 has a 2:1 FP64:FP32 throughput ratio (in the SXM variant), which is better than most GPUs. Switching to FP32 would halve memory bandwidth consumption for the dominant `nuclide_grid` data structure (24 bytes vs. 48 bytes per grid point), which would be the most impactful change given the memory-bound nature. However, this requires restructuring the `NuclideGridPoint` type, affecting the entire data pipeline.

No kernel in the codebase contains any `__syncthreads()` call. This is consistent with the algorithm design: each thread performs a fully independent lookup with no intra-block communication or shared-memory coordination. There is no synchronization overhead within kernels.

int main( int argc, char* argv[] )
{
	int version = 20;
	int mype = 0;
	double omp_start, omp_end;
	int nprocs = 1;
	unsigned long long verification;

	Inputs in = read_CLI( argc, argv );

	if( mype == 0 )
		print_inputs( in, nprocs, version );

	SimulationData SD;

	if( in.binary_mode == READ )
		SD = binary_read(in);
	else
		SD = grid_init_do_not_profile( in, mype );

	if( in.binary_mode == WRITE && mype == 0 )
		binary_write(in, SD);

	SimulationData GSD = move_simulation_data_to_device( in, mype, SD );

	if( mype == 0 )
	{
		printf("\n");
		border_print();
		center_print("SIMULATION", 79);
		border_print();
	}

	omp_start = get_time();

	if( in.simulation_method == EVENT_BASED )
	{
		if( in.kernel_id == 0 )
			verification = run_event_based_simulation_baseline(in, GSD, mype);
		else if( in.kernel_id == 1 )
			verification = run_event_based_simulation_optimization_1(in, GSD, mype);
		else if( in.kernel_id == 2 )
			verification = run_event_based_simulation_optimization_2(in, GSD, mype);
		else if( in.kernel_id == 3 )
			verification = run_event_based_simulation_optimization_3(in, GSD, mype);
		else if( in.kernel_id == 4 )
			verification = run_event_based_simulation_optimization_4(in, GSD, mype);
		else if( in.kernel_id == 5 )
			verification = run_event_based_simulation_optimization_5(in, GSD, mype);
		else if( in.kernel_id == 6 )
			verification = run_event_based_simulation_optimization_6(in, GSD, mype);
		else
		{
			printf("Error: No kernel ID %d found!\n", in.kernel_id);
			exit(1);
		}
	}
	else
	{
		printf("History-based simulation not implemented in CUDA code. Instead,\nuse the event-based method with \"-m event\" argument.\n");
		exit(1);
	}

	if( mype == 0)	
	{	
		printf("\n" );
		printf("Simulation complete.\n" );
	}

	omp_end = get_time();

	release_device_memory(GSD);

	verification = verification % 999983;

	int is_invalid_result = print_results( in, mype, omp_end-omp_start, nprocs, verification );

	return is_invalid_result;
}

int print_results( Inputs in, int mype, double runtime, int nprocs,
	unsigned long long vhash )
{
	int lookups = 0;
	if( in.simulation_method == HISTORY_BASED )
		lookups = in.lookups * in.particles;
	else if( in.simulation_method == EVENT_BASED )
		lookups = in.lookups;
	int lookups_per_sec = (int) ((double) lookups / runtime);
	
	#ifdef MPI
	int total_lookups = 0;
	MPI_Barrier(MPI_COMM_WORLD);
	MPI_Reduce(&lookups_per_sec, &total_lookups, 1, MPI_INT,
	           MPI_SUM, 0, MPI_COMM_WORLD);
	#endif

	int is_invalid_result = 1;
	
	if( mype == 0 )
	{
		border_print();
		center_print("RESULTS", 79);
		border_print();

		printf("NOTE: Timings are estimated -- use nvprof/nsys/iprof/rocprof for formal analysis\n");
		#ifdef MPI
		printf("MPI ranks:   %d\n", nprocs);
		#endif
		#ifdef MPI
		printf("Total Lookups/s:            ");
		fancy_int(total_lookups);
		printf("Avg Lookups/s per MPI rank: ");
		fancy_int(total_lookups / nprocs);
		#else
		printf("Runtime:     %.3lf seconds\n", runtime);
		printf("Lookups:     "); fancy_int(lookups);
		printf("Lookups/s:   ");
		fancy_int(lookups_per_sec);
		#endif
	}

	unsigned long long large = 0;
	unsigned long long small = 0; 
	if( in.simulation_method == EVENT_BASED )
	{
		small = 945990;
		large = 952131;
	}
	else if( in.simulation_method == HISTORY_BASED )
	{
		small = 941535;
		large = 954318; 
	}
	if( strcmp(in.HM, "large") == 0 )
	{
		if( vhash == large )
			is_invalid_result = 0;
	}
	else if( strcmp(in.HM, "small") == 0 )
	{
		if( vhash == small )
			is_invalid_result = 0;
	}

	if(mype == 0 )
	{
		if( is_invalid_result )
			printf("Verification checksum: %llu (WARNING - INAVALID CHECKSUM!)\n", vhash);
		else
			printf("Verification checksum: %llu (Valid)\n", vhash);
		border_print();
	}

	return is_invalid_result;
}

void fancy_int( long a )
{
    if( a < 1000 )
        printf("%ld\n",a);

    else if( a >= 1000 && a < 1000000 )
        printf("%ld,%03ld\n", a / 1000, a % 1000);

    else if( a >= 1000000 && a < 1000000000 )
        printf("%ld,%03ld,%03ld\n",a / 1000000,(a % 1000000) / 1000,a % 1000 );

    else if( a >= 1000000000 )
        printf("%ld,%03ld,%03ld,%03ld\n",
               a / 1000000000,
               (a % 1000000000) / 1000000,
               (a % 1000000) / 1000,
               a % 1000 );
    else
        printf("%ld\n",a);
}

Inputs read_CLI( int argc, char * argv[] )
{
	Inputs input;

	input.simulation_method = HISTORY_BASED;
	input.nthreads = 1;
	input.n_isotopes = 355;
	input.n_gridpoints = 11303;
	input.particles = 500000;
	input.lookups = 34;
	input.grid_type = UNIONIZED;
	input.hash_bins = 10000;
	input.binary_mode = NONE;
	input.kernel_id = 0;
	
	input.HM = (char *) malloc( 6 * sizeof(char) );
	input.HM[0] = 'l' ; 
	input.HM[1] = 'a' ; 
	input.HM[2] = 'r' ; 
	input.HM[3] = 'g' ; 
	input.HM[4] = 'e' ; 
	input.HM[5] = '\0';
	
	int user_g = 0;

	int default_lookups = 1;
	int default_particles = 1;
	
	for( int i = 1; i < argc; i++ )
	{
		char * arg = argv[i];

		if( strcmp(arg, "-g") == 0 )
		{	
			if( ++i < argc )
			{
				user_g = 1;
				input.n_gridpoints = atol(argv[i]);
			}
			else
				print_CLI_error();
		}
		else if( strcmp(arg, "-m") == 0 )
		{
			char * sim_type;
			if( ++i < argc )
				sim_type = argv[i];
			else
				print_CLI_error();

			if( strcmp(sim_type, "history") == 0 )
				input.simulation_method = HISTORY_BASED;
			else if( strcmp(sim_type, "event") == 0 )
			{
				input.simulation_method = EVENT_BASED;
				if( default_lookups && default_particles )
				{
					input.lookups =  input.lookups * input.particles;
					input.particles = 0;
				}
			}
			else
				print_CLI_error();
		}
		else if( strcmp(arg, "-l") == 0 )
		{
			if( ++i < argc )
			{
				input.lookups = atoi(argv[i]);
				default_lookups = 0;
			}
			else
				print_CLI_error();
		}
		else if( strcmp(arg, "-h") == 0 )
		{
			if( ++i < argc )
				input.hash_bins = atoi(argv[i]);
			else
				print_CLI_error();
		}
		else if( strcmp(arg, "-p") == 0 )
		{
			if( ++i < argc )
			{
				input.particles = atoi(argv[i]);
				default_particles = 0;
			}
			else
				print_CLI_error();
		}
		else if( strcmp(arg, "-s") == 0 )
		{	
			if( ++i < argc )
				input.HM = argv[i];
			else
				print_CLI_error();
		}
		else if( strcmp(arg, "-G") == 0 )
		{
			char * grid_type;
			if( ++i < argc )
				grid_type = argv[i];
			else
				print_CLI_error();

			if( strcmp(grid_type, "unionized") == 0 )
				input.grid_type = UNIONIZED;
			else if( strcmp(grid_type, "nuclide") == 0 )
				input.grid_type = NUCLIDE;
			else if( strcmp(grid_type, "hash") == 0 )
				input.grid_type = HASH;
			else
				print_CLI_error();
		}
		else if( strcmp(arg, "-b") == 0 )
		{
			char * binary_mode;
			if( ++i < argc )
				binary_mode = argv[i];
			else
				print_CLI_error();

			if( strcmp(binary_mode, "read") == 0 )
				input.binary_mode = READ;
			else if( strcmp(binary_mode, "write") == 0 )
				input.binary_mode = WRITE;
			else
				print_CLI_error();
		}
		else if( strcmp(arg, "-k") == 0 )
		{
			if( ++i < argc )
			{
				input.kernel_id = atoi(argv[i]);
			}
			else
				print_CLI_error();
		}
		else
			print_CLI_error();
	}

	if( input.nthreads < 1 )
		print_CLI_error();
	
	if( input.n_isotopes < 1 )
		print_CLI_error();
	
	if( input.n_gridpoints < 1 )
		print_CLI_error();

	if( input.lookups < 1 )
		print_CLI_error();

	if( input.hash_bins < 1 )
		print_CLI_error();
	
	if( strcasecmp(input.HM, "small") != 0 &&
		strcasecmp(input.HM, "large") != 0 &&
		strcasecmp(input.HM, "XL") != 0 &&
		strcasecmp(input.HM, "XXL") != 0 )
		print_CLI_error();
	
	if( strcasecmp(input.HM, "small") == 0 )
		input.n_isotopes = 68;
	else if( strcasecmp(input.HM, "XL") == 0 && user_g == 0 )
		input.n_gridpoints = 238847;
	else if( strcasecmp(input.HM, "XXL") == 0 && user_g == 0 )
		input.n_gridpoints = 238847 * 2.1;

	return input;
}

void binary_write( Inputs in, SimulationData SD )
{
	const char * fname = "XS_data.dat";
	printf("Writing all data structures to binary file %s...\n", fname);
	FILE * fp = fopen(fname, "w");

	fwrite(&SD, sizeof(SimulationData), 1, fp);

	fwrite(SD.num_nucs,       sizeof(int), SD.length_num_nucs, fp);
	fwrite(SD.concs,          sizeof(double), SD.length_concs, fp);
	fwrite(SD.mats,           sizeof(int), SD.length_mats, fp);
	fwrite(SD.nuclide_grid,   sizeof(NuclideGridPoint), SD.length_nuclide_grid, fp); 
	fwrite(SD.index_grid, sizeof(int), SD.length_index_grid, fp);
	fwrite(SD.unionized_energy_array, sizeof(double), SD.length_unionized_energy_array, fp);

	fclose(fp);
}

SimulationData binary_read( Inputs in )
{
	SimulationData SD;
	
	const char * fname = "XS_data.dat";
	printf("Reading all data structures from binary file %s...\n", fname);

	FILE * fp = fopen(fname, "r");
	assert(fp != NULL);

	fread(&SD, sizeof(SimulationData), 1, fp);

	SD.num_nucs = (int *) malloc(SD.length_num_nucs * sizeof(int));
	SD.concs = (double *) malloc(SD.length_concs * sizeof(double));
	SD.mats = (int *) malloc(SD.length_mats * sizeof(int));
	SD.nuclide_grid = (NuclideGridPoint *) malloc(SD.length_nuclide_grid * sizeof(NuclideGridPoint));
	SD.index_grid = (int *) malloc( SD.length_index_grid * sizeof(int));
	SD.unionized_energy_array = (double *) malloc( SD.length_unionized_energy_array * sizeof(double));

	fread(SD.num_nucs,       sizeof(int), SD.length_num_nucs, fp);
	fread(SD.concs,          sizeof(double), SD.length_concs, fp);
	fread(SD.mats,           sizeof(int), SD.length_mats, fp);
	fread(SD.nuclide_grid,   sizeof(NuclideGridPoint), SD.length_nuclide_grid, fp); 
	fread(SD.index_grid, sizeof(int), SD.length_index_grid, fp);
	fread(SD.unionized_energy_array, sizeof(double), SD.length_unionized_energy_array, fp);

	fclose(fp);

	return SD;
}


SimulationData move_simulation_data_to_device( Inputs in, int mype, SimulationData SD )
{
	if(mype == 0) printf("Allocating and moving simulation data to GPU memory space...\n");

	size_t sz;
	size_t total_sz = 0;

	SimulationData GSD = SD;

	sz = GSD.length_num_nucs * sizeof(int);
	gpuErrchk( cudaMalloc((void **) &GSD.num_nucs, sz) );
	gpuErrchk( cudaMemcpy(GSD.num_nucs, SD.num_nucs, sz, cudaMemcpyHostToDevice) );
	total_sz += sz;

	sz = GSD.length_concs * sizeof(double);
	gpuErrchk( cudaMalloc((void **) &GSD.concs, sz) );
	gpuErrchk( cudaMemcpy(GSD.concs, SD.concs, sz, cudaMemcpyHostToDevice) );
	total_sz += sz;

	sz = GSD.length_mats * sizeof(int);
	gpuErrchk( cudaMalloc((void **) &GSD.mats, sz) );
	gpuErrchk( cudaMemcpy(GSD.mats, SD.mats, sz, cudaMemcpyHostToDevice) );
	total_sz += sz;
	
	sz = GSD.length_unionized_energy_array * sizeof(double);
	gpuErrchk( cudaMalloc((void **) &GSD.unionized_energy_array, sz) );
	gpuErrchk( cudaMemcpy(GSD.unionized_energy_array, SD.unionized_energy_array, sz, cudaMemcpyHostToDevice) );
	total_sz += sz;

	sz = GSD.length_index_grid * sizeof(int);
	gpuErrchk( cudaMalloc((void **) &GSD.index_grid, sz) );
	gpuErrchk( cudaMemcpy(GSD.index_grid, SD.index_grid, sz, cudaMemcpyHostToDevice) );
	total_sz += sz;

	sz = GSD.length_nuclide_grid * sizeof(NuclideGridPoint);
	gpuErrchk( cudaMalloc((void **) &GSD.nuclide_grid, sz) );
	gpuErrchk( cudaMemcpy(GSD.nuclide_grid, SD.nuclide_grid, sz, cudaMemcpyHostToDevice) );
	total_sz += sz;
	
	sz = in.lookups * sizeof(unsigned long);
	gpuErrchk( cudaMalloc((void **) &GSD.verification, sz) );
	total_sz += sz;
	GSD.length_verification = in.lookups;
	
	gpuErrchk( cudaPeekAtLastError() );
	gpuErrchk( cudaDeviceSynchronize() );
	
	if(mype == 0 ) printf("GPU Intialization complete. Allocated %.0lf MB of data on GPU.\n", total_sz/1024.0/1024.0 );

	return GSD;
}

void release_device_memory(SimulationData GSD) {
	cudaFree(GSD.num_nucs);
	cudaFree(GSD.concs);
	cudaFree(GSD.mats);
	cudaFree(GSD.unionized_energy_array);
	cudaFree(GSD.nuclide_grid);
	cudaFree(GSD.verification);
}

SimulationData grid_init_do_not_profile( Inputs in, int mype )
{
	SimulationData SD;

	size_t nbytes = 0;
	
	uint64_t seed = 42;	

	if(mype == 0) printf("Intializing nuclide grids...\n");

	SD.length_nuclide_grid = in.n_isotopes * in.n_gridpoints;
	SD.nuclide_grid     = (NuclideGridPoint *) malloc( SD.length_nuclide_grid * sizeof(NuclideGridPoint));
	assert(SD.nuclide_grid != NULL);
	nbytes += SD.length_nuclide_grid * sizeof(NuclideGridPoint);
	for( int i = 0; i < SD.length_nuclide_grid; i++ )
	{
		SD.nuclide_grid[i].energy        = LCG_random_double(&seed);
		SD.nuclide_grid[i].total_xs      = LCG_random_double(&seed);
		SD.nuclide_grid[i].elastic_xs    = LCG_random_double(&seed);
		SD.nuclide_grid[i].absorbtion_xs = LCG_random_double(&seed);
		SD.nuclide_grid[i].fission_xs    = LCG_random_double(&seed);
		SD.nuclide_grid[i].nu_fission_xs = LCG_random_double(&seed);
	}

	for( int i = 0; i < in.n_isotopes; i++ )
		qsort( &SD.nuclide_grid[i*in.n_gridpoints], in.n_gridpoints, sizeof(NuclideGridPoint), NGP_compare);
	
	if( in.grid_type == NUCLIDE )
	{
		SD.length_unionized_energy_array = 0;
		SD.length_index_grid = 0;
	}
	
	if( in.grid_type == UNIONIZED )
	{
		if(mype == 0) printf("Intializing unionized grid...\n");

		SD.length_unionized_energy_array = in.n_isotopes * in.n_gridpoints;
		SD.unionized_energy_array = (double *) malloc( SD.length_unionized_energy_array * sizeof(double));
		assert(SD.unionized_energy_array != NULL );
		nbytes += SD.length_unionized_energy_array * sizeof(double);

		for( int i = 0; i < SD.length_unionized_energy_array; i++ )
			SD.unionized_energy_array[i] = SD.nuclide_grid[i].energy;

		qsort( SD.unionized_energy_array, SD.length_unionized_energy_array, sizeof(double), double_compare);

		SD.length_index_grid = SD.length_unionized_energy_array * in.n_isotopes;
		SD.index_grid = (int *) malloc( SD.length_index_grid * sizeof(int));
		assert(SD.index_grid != NULL);
		nbytes += SD.length_index_grid * sizeof(int);

		int * idx_low = (int *) calloc( in.n_isotopes, sizeof(int));
		assert(idx_low != NULL );
		double * energy_high = (double *) malloc( in.n_isotopes * sizeof(double));
		assert(energy_high != NULL );

		for( int i = 0; i < in.n_isotopes; i++ )
			energy_high[i] = SD.nuclide_grid[i * in.n_gridpoints + 1].energy;

		for( long e = 0; e < SD.length_unionized_energy_array; e++ )
		{
			double unionized_energy = SD.unionized_energy_array[e];
			for( long i = 0; i < in.n_isotopes; i++ )
			{
				if( unionized_energy < energy_high[i]  )
					SD.index_grid[e * in.n_isotopes + i] = idx_low[i];
				else if( idx_low[i] == in.n_gridpoints - 2 )
					SD.index_grid[e * in.n_isotopes + i] = idx_low[i];
				else
				{
					idx_low[i]++;
					SD.index_grid[e * in.n_isotopes + i] = idx_low[i];
					energy_high[i] = SD.nuclide_grid[i * in.n_gridpoints + idx_low[i] + 1].energy;	
				}
			}
		}

		free(idx_low);
		free(energy_high);
	}

	if( in.grid_type == HASH )
	{
		if(mype == 0) printf("Intializing hash grid...\n");
		SD.length_unionized_energy_array = 0;
		SD.length_index_grid  = in.hash_bins * in.n_isotopes;
		SD.index_grid = (int *) malloc( SD.length_index_grid * sizeof(int)); 
		assert(SD.index_grid != NULL);
		nbytes += SD.length_index_grid * sizeof(int);

		double du = 1.0 / in.hash_bins;

		for( long e = 0; e < in.hash_bins; e++ )
		{
			double energy = e * du;

			for( long i = 0; i < in.n_isotopes; i++ )
			{
				SD.index_grid[e * in.n_isotopes + i] = grid_search_nuclide( in.n_gridpoints, energy, SD.nuclide_grid + i * in.n_gridpoints, 0, in.n_gridpoints-1);
			}
		}
	}

	if(mype == 0) printf("Intializing material data...\n");
	
	SD.num_nucs  = load_num_nucs(in.n_isotopes);
	SD.length_num_nucs = 12;

	SD.mats = load_mats(SD.num_nucs, in.n_isotopes, &SD.max_num_nucs);
	SD.length_mats = SD.length_num_nucs * SD.max_num_nucs;

	SD.concs = load_concs(SD.num_nucs, SD.max_num_nucs);
	SD.length_concs = SD.length_mats;

	if(mype == 0) printf("Intialization complete. Allocated %.0lf MB of data on CPU.\n", nbytes/1024.0/1024.0 );

	return SD;
}

__device__ long grid_search( long n, double quarry, const double * __restrict__ A)
{
	long lowerLimit = 0;
	long upperLimit = n-1;
	long examinationPoint;
	long length = upperLimit - lowerLimit;

	while( length > 1 )
	{
		examinationPoint = lowerLimit + ( length / 2 );
		
		if( __ldg(&A[examinationPoint]) > quarry )
			upperLimit = examinationPoint;
		else
			lowerLimit = examinationPoint;
		
		length = upperLimit - lowerLimit;
	}
	
	return lowerLimit;
}

__host__ __device__ long grid_search_nuclide( long n, double quarry, NuclideGridPoint * A, long low, long high)
{
	long lowerLimit = low;
	long upperLimit = high;
	long examinationPoint;
	long length = upperLimit - lowerLimit;

	while( length > 1 )
	{
		examinationPoint = lowerLimit + ( length / 2 );
		
		if( A[examinationPoint].energy > quarry )
			upperLimit = examinationPoint;
		else
			lowerLimit = examinationPoint;
		
		length = upperLimit - lowerLimit;
	}
	
	return lowerLimit;
}

__device__ long grid_search_nuclide_dev( long n, double quarry, const NuclideGridPoint * __restrict__ A, long low, long high)
{
	long lowerLimit = low;
	long upperLimit = high;
	long examinationPoint;
	long length = upperLimit - lowerLimit;

	while( length > 1 )
	{
		examinationPoint = lowerLimit + ( length / 2 );
		
		if( __ldg(&A[examinationPoint].energy) > quarry )
			upperLimit = examinationPoint;
		else
			lowerLimit = examinationPoint;
		
		length = upperLimit - lowerLimit;
	}
	
	return lowerLimit;
}

__device__ int pick_mat( uint64_t * seed )
{
	double dist[12];
	dist[0]  = 0.140;
	dist[1]  = 0.052;
	dist[2]  = 0.275;
	dist[3]  = 0.134;
	dist[4]  = 0.154;
	dist[5]  = 0.064;
	dist[6]  = 0.066;
	dist[7]  = 0.055;
	dist[8]  = 0.008;
	dist[9]  = 0.015;
	dist[10] = 0.025;
	dist[11] = 0.013;
	
	double roll = LCG_random_double(seed);

	for( int i = 0; i < 12; i++ )
	{
		double running = 0;
		for( int j = i; j > 0; j-- )
			running += dist[j];
		if( roll < running )
			return i;
	}

	return 0;
}

__host__ __device__ double LCG_random_double(uint64_t * seed)
{
	const uint64_t m = 9223372036854775808ULL;
	const uint64_t a = 2806196910506780709ULL;
	const uint64_t c = 1ULL;
	*seed = (a * (*seed) + c) % m;
	return (double) (*seed) / (double) m;
}	

__device__ uint64_t fast_forward_LCG(uint64_t seed, uint64_t n)
{
	const uint64_t m = 9223372036854775808ULL;
	uint64_t a = 2806196910506780709ULL;
	uint64_t c = 1ULL;

	n = n % m;

	uint64_t a_new = 1;
	uint64_t c_new = 0;

	while(n > 0) 
	{
		if(n & 1)
		{
			a_new *= a;
			c_new = c_new * a + c;
		}
		c *= (a + 1);
		a *= a;

		n >>= 1;
	}

	return (a_new * seed + c_new) % m;
}

// Optimized calculate_micro_xs using __ldg for read-only data
__device__ void calculate_micro_xs(   double p_energy, int nuc, long n_isotopes,
                           long n_gridpoints,
                           const double * __restrict__ egrid, const int * __restrict__ index_data,
                           const NuclideGridPoint * __restrict__ nuclide_grids,
                           long idx, double * __restrict__ xs_vector, int grid_type, int hash_bins )
{
	double f;
	const NuclideGridPoint * low;
	const NuclideGridPoint * high;
	long nuc_start = (long)nuc * n_gridpoints;

	if( grid_type == NUCLIDE )
	{
		idx = grid_search_nuclide_dev( n_gridpoints, p_energy, &nuclide_grids[nuc_start], 0, n_gridpoints-1);

		if( idx == n_gridpoints - 1 )
			low = &nuclide_grids[nuc_start + idx - 1];
		else
			low = &nuclide_grids[nuc_start + idx];
	}
	else if( grid_type == UNIONIZED)
	{
		int grid_idx = __ldg(&index_data[idx * n_isotopes + nuc]);
		if( grid_idx == n_gridpoints - 1 )
			low = &nuclide_grids[nuc_start + grid_idx - 1];
		else
			low = &nuclide_grids[nuc_start + grid_idx];
	}
	else // Hash grid
	{
		int u_low = __ldg(&index_data[idx * n_isotopes + nuc]);

		int u_high;
		if( idx == hash_bins - 1 )
			u_high = n_gridpoints - 1;
		else
			u_high = __ldg(&index_data[(idx+1)*n_isotopes + nuc]) + 1;

		double e_low  = __ldg(&nuclide_grids[nuc_start + u_low].energy);
		double e_high = __ldg(&nuclide_grids[nuc_start + u_high].energy);
		int lower;
		if( p_energy <= e_low )
			lower = 0;
		else if( p_energy >= e_high )
			lower = n_gridpoints - 1;
		else
			lower = grid_search_nuclide_dev( n_gridpoints, p_energy, &nuclide_grids[nuc_start], u_low, u_high);

		if( lower == n_gridpoints - 1 )
			low = &nuclide_grids[nuc_start + lower - 1];
		else
			low = &nuclide_grids[nuc_start + lower];
	}
	
	high = low + 1;
	
	// Load both grid points using __ldg
	double low_energy = __ldg(&low->energy);
	double high_energy = __ldg(&high->energy);
	double low_total = __ldg(&low->total_xs);
	double high_total = __ldg(&high->total_xs);
	double low_elastic = __ldg(&low->elastic_xs);
	double high_elastic = __ldg(&high->elastic_xs);
	double low_absorbtion = __ldg(&low->absorbtion_xs);
	double high_absorbtion = __ldg(&high->absorbtion_xs);
	double low_fission = __ldg(&low->fission_xs);
	double high_fission = __ldg(&high->fission_xs);
	double low_nu_fission = __ldg(&low->nu_fission_xs);
	double high_nu_fission = __ldg(&high->nu_fission_xs);

	f = (high_energy - p_energy) / (high_energy - low_energy);

	xs_vector[0] = high_total - f * (high_total - low_total);
	xs_vector[1] = high_elastic - f * (high_elastic - low_elastic);
	xs_vector[2] = high_absorbtion - f * (high_absorbtion - low_absorbtion);
	xs_vector[3] = high_fission - f * (high_fission - low_fission);
	xs_vector[4] = high_nu_fission - f * (high_nu_fission - low_nu_fission);
}

__device__ void calculate_macro_xs( double p_energy, int mat, long n_isotopes,
                         long n_gridpoints, const int * __restrict__ num_nucs,
                         const double * __restrict__ concs,
                         const double * __restrict__ egrid, const int * __restrict__ index_data,
                         const NuclideGridPoint * __restrict__ nuclide_grids,
                         const int * __restrict__ mats,
                         double * __restrict__ macro_xs_vector, int grid_type, int hash_bins, int max_num_nucs )
{
	int p_nuc;
	long idx = -1;	
	double conc;

	#pragma unroll
	for( int k = 0; k < 5; k++ )
		macro_xs_vector[k] = 0;

	if( grid_type == UNIONIZED )
		idx = grid_search( n_isotopes * n_gridpoints, p_energy, egrid);	
	else if( grid_type == HASH )
	{
		double du = 1.0 / hash_bins;
		idx = p_energy / du;
	}
	
	int n_nucs = __ldg(&num_nucs[mat]);
	int mat_offset = mat * max_num_nucs;
	
	for( int j = 0; j < n_nucs; j++ )
	{
		double xs_vector[5];
		p_nuc = __ldg(&mats[mat_offset + j]);
		conc = __ldg(&concs[mat_offset + j]);
		calculate_micro_xs( p_energy, p_nuc, n_isotopes,
		                    n_gridpoints, egrid, index_data,
		                    nuclide_grids, idx, xs_vector, grid_type, hash_bins );
		#pragma unroll
		for( int k = 0; k < 5; k++ )
			macro_xs_vector[k] += xs_vector[k] * conc;
	}
}

unsigned long long run_event_based_simulation_baseline(Inputs in, SimulationData GSD, int mype)
{
	if( mype == 0)	printf("Running baseline event-based simulation...\n");

	int nthreads = 256;
	int nblocks = ceil( (double) in.lookups / (double) nthreads);

	xs_lookup_kernel_baseline<<<nblocks, nthreads>>>( in, GSD );
	gpuErrchk( cudaPeekAtLastError() );
	gpuErrchk( cudaDeviceSynchronize() );
	
	if( mype == 0)	printf("Reducing verification results...\n");

	unsigned long verification_scalar = thrust::reduce(thrust::device, GSD.verification, GSD.verification + in.lookups, 0);
	gpuErrchk( cudaPeekAtLastError() );
	gpuErrchk( cudaDeviceSynchronize() );

	return verification_scalar;
}

__launch_bounds__(256, 4)
__global__ void xs_lookup_kernel_baseline(Inputs in, SimulationData GSD )
{
	const int i = blockIdx.x * blockDim.x + threadIdx.x;

	if( i >= in.lookups )
		return;

	uint64_t seed = STARTING_SEED;	

	seed = fast_forward_LCG(seed, 2*i);

	double p_energy = LCG_random_double(&seed);
	int mat         = pick_mat(&seed); 
		
	double macro_xs_vector[5] = {0};
		
	calculate_macro_xs(
			p_energy,
			mat,
			in.n_isotopes,
			in.n_gridpoints,
			GSD.num_nucs,
			GSD.concs,
			GSD.unionized_energy_array,
			GSD.index_grid,
			GSD.nuclide_grid,
			GSD.mats,
			macro_xs_vector,
			in.grid_type,
			in.hash_bins,
			GSD.max_num_nucs
			);

	double max = -1.0;
	int max_idx = 0;
	#pragma unroll
	for(int j = 0; j < 5; j++ )
	{
		if( macro_xs_vector[j] > max )
		{
			max = macro_xs_vector[j];
			max_idx = j;
		}
	}
	GSD.verification[i] = max_idx+1;
}

	sampling_kernel<<<nblocks, nthreads>>>( in, GSD );

__launch_bounds__(256, 8)
__global__ void sampling_kernel(Inputs in, SimulationData GSD )
{
	const int i = blockIdx.x * blockDim.x + threadIdx.x;

	if( i >= in.lookups )
		return;

	uint64_t seed = STARTING_SEED;	

	seed = fast_forward_LCG(seed, 2*i);

	double p_energy = LCG_random_double(&seed);
	int mat         = pick_mat(&seed); 

	GSD.p_energy_samples[i] = p_energy;
	GSD.mat_samples[i] = mat;
}

__launch_bounds__(256, 4)

	double max = -1.0;

	#pragma unroll
	for(int j = 0; j < 5; j++ )
	{

		{

double rn_v(void)
{
	static unsigned long seed = 1337;
	double ret;
	unsigned long n1;
	unsigned long a = 16807;
	unsigned long m = 2147483647;
	n1 = ( a * (seed) ) % m;
	seed = n1;
	ret = (double) n1 / m;
	return ret;
}

size_t estimate_mem_usage( Inputs in )
{
	size_t single_nuclide_grid = in.n_gridpoints * sizeof( NuclideGridPoint );
	size_t all_nuclide_grids   = in.n_isotopes * single_nuclide_grid;
	size_t size_UEG            = in.n_isotopes*in.n_gridpoints*sizeof(double) + in.n_isotopes*in.n_gridpoints*in.n_isotopes*sizeof(int);
	size_t size_hash_grid      = in.hash_bins * in.n_isotopes * sizeof(int);
	size_t memtotal;

	if( in.grid_type == UNIONIZED )
		memtotal          = all_nuclide_grids + size_UEG;
	else if( in.grid_type == NUCLIDE )
		memtotal          = all_nuclide_grids;
	else
		memtotal          = all_nuclide_grids + size_hash_grid;

	memtotal          = ceil(memtotal / (1024.0*1024.0));
	return memtotal;
}

	return (double) us_since_epoch / 1.0e6;
}
