     SYCL uses the last dimension as the fastest-moving dimension.
     Incorrect translation can harm memory coalescing, causing more memory traffic

  5. Preserve memory coalescing.
     Rework indexing so adjacent work-items access adjacent memory whenever possible.

  12. Be careful with shuffle and collective operations.
