① Launch syntax

Magic brackets → explicit queue

CUDA's <<<nblocks, nthreads>>> is compiler-level syntax understood only by nvcc. SYCL replaces it with standard C++: a queue, a handler, and an nd_range object that spells out the same grid geometry explicitly.

② Thread index

Implicit registers → method calls

CUDA exposes blockIdx, blockDim, and threadIdx as implicit hardware registers available inside any __global__ function. SYCL passes an nd_item context object and requires explicit method calls — get_group, get_local_range, get_local_id — to retrieve the same values.

③ Function qualifier

__global__ → inline

__global__ marks a CUDA entry point callable from host code. In SYCL there is no such qualifier — device code is standard C++. The kernel becomes a plain inline function called from within the lambda, with i passed as an ordinary argument rather than read from a GPU register.

Physics kernel body (random energy sampling, binary search, macroscopic XS calculation) is identical in both versions — only the parallel dispatch infrastructure changed.
